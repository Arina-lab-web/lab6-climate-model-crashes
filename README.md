## Описание задачи
Необходимо решить задачу бинарной классификации: определить, произойдет ли сбой (`crash`) или симуляция пройдет успешно (`success`) в климатических моделях.

## Датасет
- **Название:** Climate Model Simulation Crashes
- **Источник:** [UCI Machine Learning Repository](https://archive.ics.uci.edu/dataset/252/climate+model+simulation+crashes)
- **Объем:** 540 наблюдений, 21 числовой признак.
- **Особенность:** Сильный дисбаланс классов (91.5% успех, 8.5% сбой).

## Использованные методы
1. **Базовая модель:** Decision Tree (для оценки переобучения).
2. **Ансамблевые методы (по варианту):**
   - Random Forest
   - AdaBoost
   - LightGBM

Для борьбы с дисбалансом использовался параметр `class_weight='balanced'` (и `is_unbalance=True` для LightGBM).

## Итоговые результаты на тестовой выборке

| Модель | Test Accuracy | Test F1 (crash) | Test Recall (crash) | Test ROC-AUC |
| :--- | :---: | :---: | :---: | :---: |
| Decision Tree (max_depth=3) | 0.907 | 0.444 | 0.444 | 0.722 |
| **Random Forest** | **0.954** | **0.667** | **0.556** | **0.901** |
| AdaBoost | 0.944 | 0.571 | 0.444 | 0.884 |
| LightGBM | 0.944 | 0.625 | 0.556 | 0.888 |

*Лучшей моделью признан **Random Forest** как наиболее стабильный по метрикам F1 и ROC-AUC.*

## Ключевые выводы
- Ансамблевые методы значительно превзошли одиночное дерево решений.
- SHAP-анализ показал, что более 55% важности модели сосредоточено в двух признаках: `vconst_2` и `vconst_corr`. Их высокие значения физически стабилизируют симуляцию и снижают риск сбоя.
